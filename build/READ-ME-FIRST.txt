Few Examples, Far Transfer
An interactive map of sample efficiency against transfer breadth,
across 37 human, animal and machine learners.

TO VIEW
  Open index.html in any web browser (double-click it, or drag it
  onto a browser window). Nothing to install, no server needed, and
  it works with no internet connection.

WHAT IT IS
  A single self-contained HTML file. All styling is CSS in the page,
  all behaviour is plain JavaScript in the page, and the scatter plot
  is hand-built SVG. No frameworks, no libraries, no build step. The
  three typefaces are embedded in the file so it looks the same
  offline.

HOW TO USE IT
  - Lifetime / Total switches how experience is counted, and moves
    the points. This is the main argument of the piece.
  - Show the shift draws each point's movement between the two.
  - Ages labels the human points by age, from birth to 65+.
  - The four family chips filter the map.
  - Click any point to read its full record on the right.
  - Map / Table switches to a sortable-by-eye table of all 37 points
    with every field, which is also the accessible equivalent.
